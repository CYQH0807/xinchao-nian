## 行为与集成

- 增加 proof/slip、情绪标记、衰减与陈旧提示；Xi 工具 schema、服务、MCP 与核心引擎完整透传。
- her_ok/helped_ack 需要 exchange 中真实的人类原话；统一事件入口覆盖 heartbeat，不信任客户端 exchangeObserved。事件处理后删除原话，不写入状态和审计。
- 增加 SSE、satisfy、now-lines、虚拟身体与 call 接口。SSE 限连接并清理慢消费者；短期内容有容量/TTL限制。
- satisfy 先推进此前时间再施加满足，事件 ID 去重，避免重放及错误改变此前时段。
- 三个开关在代码层默认关闭；按用户后续选择，独立构建 override 已设 `PULSE=true`、`DRIVE_POOL=true`、`DRIVE_PROMPTS_ENABLED=true`，同时配套 Bridge、自身信号、话术文件及默认频率限制。
- Jev 策略未改：仅拦截定时唤醒，其他事件仍直接进入 Life。
- Ombre 客户端识别 MCP/JSON-RPC 错误；仅明确 Unknown tool 时降级旧 OB，避免把错误正文当记忆。
- 修复 Xi 回合收尾读取历史失败时图片上下文未清理的问题。

## 构建

在本心潮工作区根目录执行：

```sh
docker build -t xi-upgrade/xinchao:4.2.0-local ./xinchao
docker build --build-arg INSTALL_CLOUDFLARED=0 --label org.opencontainers.image.revision=877c5cc -t xi-upgrade/ombre-brain:3.6.14-877c5cc /Users/goupaipai/Documents/GitHub/Ombre-Brain
```

联合配置必须显式叠加 `compose.ombre-independent.yaml`，并设置 `OMBRE_BRAIN_REPO` 指向上述独立仓库；原 compose 单独使用仍引用内嵌 OB，不能作为本次版本交付入口。可用 `docker compose -f compose.yaml -f compose.ombre-independent.yaml config` 检查合并配置；实际启动需使用专门测试配置，避免复用生产数据卷。
