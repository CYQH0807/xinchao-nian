# 汐的互动规则

`interaction-rules.xi.json` 保存可随仓库追踪的汐用配置；运行时读取同目录的 `interaction-rules.json`。正式文件沿用上游约定，被 Git 忽略，后续私人调整不会自动进入仓库。

首次应用或明确要恢复这份配置时，在仓库根目录执行：

```bash
cp xinchao/configs/interaction-rules.xi.json xinchao/configs/interaction-rules.json
```

不要在每次部署时自动覆盖已有正式配置。当前 Compose 已将配置目录挂入 `/app/configs`，服务在分类时最多缓存一分钟，无需重建或重启。其他部署应确认挂载与 `INTERACTION_RULES_PATH`。

原对话确认了首轮五项方向和目标数量，但引用没有提供候选 JSON 附件，因此首轮按要求重建。本轮再根据汐的反馈及用户授权调整，下面记录当前实际选词，不声称逐字复原原附件。

## 判定边界

词表用于核验模型已经给出的互动分类，不会仅凭关键词主动创建事件，也不是 11 项驱力各自的完整计算公式。驱力响应仍由 `src/engine.js`、`src/dimensions.js` 及相关情绪模块负责。

移除强心动词后，模型判为 `heavy` 且正文达到上游长度条件仍可保留重心动；移除“偷偷”后，模型明确判为“害羞”仍可保留该细项。疲劳词只补充人类本人“心疼”事件的依据，虚构语境仍被阻断。日常离开不会直接被推断成被晾着；长期分别边界保留上游行为。

“抱”“亲亲”仍由模型识别为日常轻亲昵，不加入强心动词表；避免单字“抱”误匹配“抱怨”。烦闷采用“心里烦”“烦得很”，不添加裸字“烦”，避免把“我烦你”也当作心疼依据。`harsh` 当前明确覆盖为 9 项：滚、烦死、别烦、真的生气、我生气了、别跟我说话、闭嘴、讨厌死你、分手。“小笨蛋”“傻瓜”“别碰我”不在其中。它是包含匹配；“别说话了，快睡”不再命中，“别跟我说话”仍命中。

30 分钟窗口适用于模型已判为冲突、近期有 affection 或 intimacy 记录、张力低于 0.6 且未命中狠话的情形，并非仅对昵称生效。张力达到 0.6、没有亲近记录或距离亲近已满 30 分钟时，仍保留冲突分类。`harsh` 用于阻止这一软化，不会单独创建冲突事件。

运行环境的 `MODEL_ENABLED=false` 时，不会自动分类 exchange。此配置不负责启用模型或改变默认 8 分钟分类间隔。
